## Getting Help

### Best Practices

1. **Search first** - Most questions have been answered
2. **Provide context** - Include code, error messages, versions
3. **Be specific** - Vague questions get vague answers
4. **Follow up** - Share solutions for others

### Where to Ask

| Question Type | Best Place |
|---------------|------------|
| API errors | Betfair Developer Forum |
| betfairlightweight/flumine | GitHub Issues, Betcode Slack |
| Trading strategies | Bet Angel Forum |
| Scraping help | UK Betting Forum, Stack Overflow |
| General Python | Stack Overflow |

### Response Times

| Platform | Typical Response |
|----------|------------------|
| Stack Overflow | Hours to days |
| Bet Angel Forum | Hours to days |
| GitHub Issues | Days to weeks |
| Discord | Minutes to hours |
